## 🚀 Featured Projects  

### 🛒 E-Commerce AI Chatbot
🚀 **Impact:** Understands natural language and retrieves real product data from 6,795+ Flipkart products across 90+ categories

- Built a full hybrid intelligent system powered by RAG + LLM + SQL
- 4-layer hybrid routing: Semantic Router → FAQ Fallback → DB Check → Intent Check
- Natural language filters like "budget friendly", "under 50k" mapped to SQL conditions
- FAQ queries handled via RAG pipeline with ChromaDB
- Data collected via custom web scraping pipeline built from scratch

🔗 **Live Demo:**
https://aditi-ecommerce-ai-chatbot.streamlit.app/

💻 **GitHub Repo:**
https://github.com/AditiPatil31/E-commerce-Chatbot

### 🏠 Real Estate Research Assistant
🚀 **Impact:** Converts multiple real estate articles into a searchable AI knowledge base

- RAG-powered system using LangChain + ChromaDB + Groq (Llama 3.3)
- Users paste article URLs → chunked → embedded → queried in natural language
- Answers grounded in source content with full source attribution
- Smart chunk overlap, duplicate embedding prevention, session-based chat history

🔗 **Live Demo:**
https://aditi-real-estate-assistant.streamlit.app/
